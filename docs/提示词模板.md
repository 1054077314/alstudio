# 提示词模板

## 万能模板（任何场景先套这个）

```
背景：（我是谁，现在什么情况，相关数字和事实全列出来）
任务：（要你干什么，一句话）
要求：
- 输出格式（多少字 / 分几条 / 先结论后理由）
- 有不确定的直接说不知道，别编
```

---

## 按场景选

### 1. 做选择（租房、买什么、选方案）

```
背景：我的情况和数字（钱、时间、限制条件、我不确定的地方）
选项：A是… B是…（价格/代价写清楚）
任务：帮我选一个，算清楚账
要求：X字内，先说选哪个再给理由
```

### 2. 写东西（文案、邮件、报告）

```
背景：写给谁看的，他们关心什么，用来干什么
任务：写一篇（主题），要点是（1、2、3）
要求：
- X字左右，语言风格（口语/正式）
- 不要空话套话，每个观点带具体例子
```

### 3. 改代码 / 技术问题

```
背景：环境是什么（语言、框架、版本），报错信息原文贴上来
任务：（直接说"修改"或"解释"，别说"帮我看看"）
要求：
- 只改和问题相关的部分，别顺手重构
- 改完说明每处改动的原因
```

### 4. 学东西 / 让它解释

```
背景：我已知的水平（零基础 / 懂X但不懂Y）
任务：解释（概念），用（生活类比 + 一个具体例子）
要求：不超过X字，别堆术语，最后给一个我能动手验证的小练习
```

### 5. 检查 / 找茬

```
背景：（材料粘贴进来）这是我写的（东西）
任务：按这几个标准挑毛病：（标准1、标准2、标准3）
要求：每条问题指出位置+原因+怎么改，没问题的方面不用夸
```

---

## 发出前 6 秒检查

1. 影响结论的数字都写了吗？（价格、日期、期限、不确定项）
2. 要什么样的答案说了吗？（字数、条数、格式）
3. 两句话有没有打架？（比如又要详细又要50字）
4. 加了"不知道就说不知道"吗？
5. 动词明确吗？（"改成X"而不是"建议一下X"）

不满意就**补信息重问**，不要换花样重问。
